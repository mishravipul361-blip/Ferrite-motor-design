Neighbours or same-sign pairs: which should you use?

As built (neighbours)

R = (−12 +1) ∥ (+6 −7). Each path joins two adjacent coils. Series links span 30° and all six fit on one copper level.

Your sketch (same sign)

R = (+1 +6) ∥ (−7 −12). Each path joins two coils 150° apart. Series links span 150°, overlap each other and need a second copper level.

Switch the selector above: every coil current, every tooth MMF and the field stay exactly the same, because in both pairings each path holds one coil at 0° and one at 30° electrical (path EMF 1.932 ∠ 15° for R). The pairing only changes the copper of the series links. Neighbour pairing is shorter, lighter and lower-loss, so it is the one built. If you want the busbar exactly as drawn, it can be rebuilt with long links.
